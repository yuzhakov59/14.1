# Проект "ООП-подход"

## Описание:

Это несколько классов и тесты на них.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:yuzhakov59/14.1.git
```

2. Установите зависимости:
```
requires = ["poetry-core>=2.0.0,<3.0.0"]
build-backend = "poetry.core.masonry.api"
```

## Использование:

1. class Category принимает имя категории, статус, список продуктов.
2. считает количество категорий и количество продуктов.
2. class Product принимает имя продукта, статус, цену продукта, количество штук.
3. тесты на class Category
4. тесты на class Product
